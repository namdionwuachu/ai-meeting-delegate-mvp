# AI Agent Governance

## Context is the Competitive Advantage

Models are increasingly commodities.

Differentiation comes from:

- organisational context
- workflow integration
- domain expertise
- governance

## Trust Model

Trust is built through:

- observability
- auditability
- accountability
- explainability

## Sustainability

AI governance should include:

- token budgets
- cost controls
- model selection policies
- workload classification

## Build vs Buy

The decision should consider:

- control
- support
- maintenance
- long-term economics
