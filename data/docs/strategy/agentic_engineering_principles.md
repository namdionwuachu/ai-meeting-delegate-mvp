# Agentic Engineering Principles

## Context Matters More Than Prompts

Agent failures are often context failures rather than model failures.

Engineering standards should be encoded into reusable artefacts:

- skills.md
- architecture patterns
- coding standards
- guardrails
- reference implementations

Agents should be given organisational context and engineering constraints rather than isolated instructions.

## Human Oversight

Autonomy should be graduated.

The objective is not full autonomy but appropriate autonomy.

Human judgement should be inserted at high-value decision points.
