# Future of Data Engineering

## Observation

The highest value skill is increasingly intent definition and evaluation rather than implementation.

## Emerging Patterns

1. Prompt as specification
2. Evaluation as the bottleneck
3. Human-in-the-loop as a design pattern
4. Governance by default
5. Explainability and auditability

## Implication

Data engineers increasingly become system designers, evaluators and governors of autonomous systems.
